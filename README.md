# Wenlock Hospital Development

This repository contains the source code for projects under development for Wenlock Hospital, Mangaluru. This work is being done as part of the Udal DC Fellowship Program.

## Udal DC Fellowship Program

The Udal DC Fellowship Program (Urban & District Advancement through Localising Innovations) is an initiative in Mangaluru designed to foster civic engagement and innovation. One of its primary themes is "Public Healthcare Service."

## Project Focus

The development efforts are currently focused on creating a **Centralized Patient & Resource Management System** for Wenlock Hospital, the largest government hospital in the Dakshina Kannada district.
